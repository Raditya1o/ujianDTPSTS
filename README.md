# Sistem Pelaporan Kerusakan Fasilitas Sekolah

Aplikasi web untuk mencatat, memantau, dan menindaklanjuti laporan kerusakan fasilitas di lingkungan sekolah secara terstruktur.

## Tujuan Aplikasi
- **Pelaporan Kerusakan:** Memudahkan pengguna melaporkan fasilitas sekolah yang rusak beserta detail lokasi dan kondisinya.
- **Pemantauan & Tindak Lanjut:** Membantu pengelola/admin memantau status laporan serta menindaklanjuti perbaikan fasilitas.

## Teknologi / Architecture
- **Frontend:** HTML, CSS (`syle.css`), dan Tailwind CSS
- **Backend:** PHP 
- **Database:** MySQL
